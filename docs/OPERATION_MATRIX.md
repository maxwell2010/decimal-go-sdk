# Official JS / Go operation matrix
Pinned sources are recorded in [sources.json](sources.json). Regenerate with `tools/compare.py`.
93 active EVM public write entry points are in the pinned JS index. The earlier regex count 94 included `mintNFT` inside a block comment. Block and line comments are now excluded. These are API entry points, not unique chain transaction types. The official Go methods directory has 58 exported functions including builders and signing helpers. Name matches are evidence of a counterpart, not semantic equivalence.
`pinned-ABI-builder` means at least one related write signature has a typed builder; it does not mean all variants of that JS workflow are equivalent or deployed. Each builder accepts raw base units; JS may do approvals, conversions, permit signing, metadata extraction and other orchestration. `BuildReferenceOperation` uses ABI-level arguments, not the JS parameter order. Explicit deployment ABI is required for unmatched variants.
Classification follows the actual submission contract, excluding `estimateGas`/`callStatic` targets. In particular, the three NFT reset workflows estimate against Delegation upstream but submit against DelegationNFT; coin reset signatures are not evidence of NFT reset coverage. Private methods do not extend the body of a preceding public method. `BuildReferenceOperationSignature` selects an exact overload while retaining the operation and profile restrictions.
