# Критерии стабильного релиза

[English](STABLE_RELEASE.md) | [Валидация](VALIDATION.md) | [Ресурсы для приёмки](ACCEPTANCE.md)

Текущий preview не подтверждает production-совместимость deployment. Для стабильного релиза нужны следующие доказательства в заявленной области поддержки:

- Воспроизводимые закреплённые ABI и исходники, описанный публичный API, проверенные установка, обновление и откат обоих модулей.
- Успешные сборки и тесты на Linux/Windows, проверки race, ограниченные fuzz-кампании и отсутствие достижимых уязвимостей в датированном сканировании зависимостей.
- Настоящее локальное исполнение доступных официальных артефактов EVM с provenance, проверкой состояния, событий и ожидаемых отказов. Исторические фикстуры отделяются от сетевых deployment.
- Подтверждённые идентичность контракта и схема подписи каждого поддерживаемого поколения. Исторический артефакт Checks из комплекта и наблюдённая официальная реализация используют разные профили подписи. Наблюдённый код принимает помощник JS-профиля при локальном исполнении; инициализация, обеспечение и settlement публичного экземпляра требуют отдельной приёмки.
- Отдельно разрешённая ограниченная приёмка в testnet: необходимые роли, receipt, комиссии и изменения состояния. Публичная отправка транзакций в этой работе не разрешена.
- Точные официальные ABI и источники proof для пока не подтвержденных bridge-v2 и других расширений deployment до объявления их принятыми. ABI recovery-поколения Delegation, включая NFT tuple10, уже доступен из закрепленного официального Go-binding и не относится к неизвестным интерфейсам. Наличие исходника не подтверждает каждый живой proxy и stateful-маршрут. Покрытие исторических Cosmos-схем не означает допуск каждого типа в качестве самостоятельной native-транзакции.

Для первых трёх групп есть исполняемые preview-проверки в описанных пределах фикстур. Они не закрывают последние три группы. Приём Safe/permit в публичных deployment, инициализация mainnet Checks, недоступные ABI и публичный settlement остаются неподтверждёнными. Процент готовности и stable tag из локальных тестов не выводятся.

[Локальный аудит 30 октября](STABLE_READINESS_20261030.md) закрывает некорректные NFT-wrapper, изменение receipt через результат декодирования и потерю отмены контекста в Cosmos-транспортах. Воспроизведение recovery ABI и откат опубликованных модулей теперь проверены исполняемыми сценариями. Эти исправления входят в preview.12. Результаты удаленного CI для проверенного commit доступны на странице релиза GitHub; они не подтверждают публичную stateful-приемку.
