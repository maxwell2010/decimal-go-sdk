# Contract API

Generated typed argument/result wrappers use raw base units. `Build*` is offline; `Read*` calls RPC. Result fields `Value0`, `Value1`, etc. follow ABI output order. Tuple field names follow the ABI. Overloads receive deterministic numeric suffixes, ordered by the full signature.
